## 3. Що лишається відкритим (16 прогалин)

**Блокує запис:**
1. **#2** власний readback як точка повернення. Заводський HEX його **не
   замінює** — у ньому немає прив'язки іммобілайзера й адаптацій цього блоку.
2. **#10** який лімітер кусає на WOT. Канали пишуться нулями; потрібен
   рідний протокол VAG (група 008), не OBD-II Mode 01.
3. **#19** T3: датчик чи модель.
4. **#20** компресорна карта BV39A-0072.

**Один вечір закриває #10 і #19** — дамп усіх вимірювальних груп на
прогрітому холостому, потім цільовий лог на розгоні.

## 4. Стан інструментів

`calharness` — 120 тестів проходять. Усі 19 зауважень ревю усунені, і це
**перевірено виконанням**, а не прийнято на слово:

| Було | Стало |
|---|---|
| псування заголовка карти → `PASS` | → **`HARD_FAIL`** |
| 512 КБ зріз → «модифікація коду» | → `MAP_VALUE` |
| `VAL_BLK` 80 б → 78 «невідомих» | → `KNOWN_CALIBRATION: 80` |
| ідентичність `03G906021AB` | → **`03G906021QJ`** + HW окремо |
| `Gkf_Ws16` не декодується | → декодується, **31 карта кутів відкрилась** |
| `TAB_VERB` тихо ставав Identical | → `UnsupportedConversionError` |
| немає провенансу в моделях | → `a2l_sha256` + `bin_sha256` |

`correlator` — `AxisResolverRegistry` реалізовано; у режимі `STRICT`
відмовляється підставляти момент замість `PCR_qDes`. Перевірено запуском.

`kb_a2l_doc_linter` — тепер знає й `FUNCTION`-імена (486 штук). Спіймав два
власні рядки автора без мітки, тобто працює в обидва боки.
