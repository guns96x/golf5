# Generated remote specialist snapshot

This directory is generated by `ecu-kb/remote_bridge.py`.

Do not hand-edit generated JSON files. The canonical mutable source is the local
SQLite database at `ecu-kb/knowledge/kb.sqlite3`, which is intentionally
excluded from Git.

Expected generated files after a local publish:

- `manifest.json`
- `claims.json`
- `retractions.json`
- `gaps.json`
- `conflicts.json`
- `corpus.json` — metadata-only ECU artefact registry and match classes
- `a2l/*.json`

External AI clients should start from
`docs/CHATGPT-KB-BRIDGE.md` and `manifest.json`.

If `manifest.json` is absent, the local canonical database has not yet been
published through the bridge. In that case, versioned `ecu-kb/claims/*.json`
and project documents can still be inspected, but they are not a complete
replacement for current SQLite state because retractions and gap status live in
the database.
