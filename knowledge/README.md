# EDC16U34 Local Engineering Library & Knowledge Base

This directory hosts the structured raw assets, documents, firmware images, and the relational database `edc16_knowledge.db` according to the [Bootstrap Pack Specification](../docs/knowledge/EDC16U34_KNOWLEDGE_BOOTSTRAP_PACK.md).

For full engineering documentation, consult:
- **[Knowledge Documentation Center](../docs/knowledge/README.md)**
- **[Master Research Policy](../docs/knowledge/RESEARCH_POLICY.md)**

## Directory Layout
- `00_inbox/`: Unclassified incoming technical materials.
- `01_oem/`: Authoritative Bosch, Volkswagen, BorgWarner, and Ross-Tech documentation.
- `02_standards/`: ASAM MCD-2 MC / ASAP2 specifications.
- `03_books/`: Textbooks on diesel engines, combustion, turbocharging, and control theory.
- `04_papers/`: Peer-reviewed SAE and control engineering papers on VGT/EGR.
- `05_tools_docs/`: Documentation for WinOLS, INCA, pyA2L, and diagnostic tools.
- `06_project_specific/`: ECU, BLS engine, and BV39 turbo technical datasheets.
- `07_community/`: Screened forum evidence (TDIClub, EcuConnections).
- `08_firmware/`: Immutable original binaries, modified images, and binary diffs.
- `09_logs/`: Raw and normalized VCDS CSV logs and telemetry.
- `10_a2l_damos/`: ASAP2 definitions and map descriptor files.
- `11_extracted/`: Parsed map definitions and JSON exports.
- `12_conflicts/`: Documented evidence conflicts and resolutions.
- `13_reports/`: Formal audit reports and engineering summaries.
